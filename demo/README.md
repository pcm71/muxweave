# demo —— 离线演示入口（第 9 周）

要求：**全套演示优先离线完成**，备份录像与完整历史运行目录，现场不依赖网络。

计划内容：

1. `demo/index.html` —— 静态报告入口（读取 `reports/` 下同一次运行的 JSON/CSV 生成，不手填数字）。
2. `demo/script_5min.md` —— 五分钟演示脚本（0:00～5:00 分段，见方案第 15 节）。
3. `demo/backup/` —— 同版本录屏与历史运行目录快照。

纪律：

- 必须标注"实时运行"还是"历史运行"，**不可用动画伪装计算**。
- 存在回退时用文字说明原因，不只靠红绿颜色。
- 没有功耗/后端时序测量时，不加入推测性功耗百分比与最高频率数字。
- 实时证明超时，先说明状态，再切换到可核查的历史记录，不修改页面数值掩盖失败。
