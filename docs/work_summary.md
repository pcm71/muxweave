## 一、我们在做什么

**赛题**：中科亿海微 选题二「多路选择器 PMUX 结构优化」。

**问题**：FPGA 综合工具在把电路变成查找表（LUT）时，遇到"多路选择器"（根据配置从多路输入里选一路输出）这种结构，
会**占用大量逻辑资源**。我们的任务是写一个优化算法，让它**占更少的资源**，同时**功能完全不变**。

**硬性约束**（来自赛题与主办方答疑）：

| 约束 | 出处 |
|---|---|
| 必须用 Yosys 框架，映射器必须**统一用自带的 `abc9`** | 答疑 C53-1 |
| 优化代码要**编进 yosys 主程序**，不能用 `plugin` 加载 | 答疑 C53-2 |
| **其他单元不能增加**（主要看 LUT 逻辑单元） | 答疑 C53-3 |
| 有**任意一个测试用例功能不等价**，则本项 **0 分**且其余项不计分 | 赛题第 7 页 |

## 二、我们怎么做（一句话原理）

> 官方默认喂给映射器 `abc9` 的**一串优化指令里，有几条实际上在帮倒忙**。
> 我们把这一串指令逐步拆开、逐条测试，找出有害的删掉、有用的补上，重新组合成更好的指令序列。

**没有更换映射器**（仍用官方的 `abc9`），也没有改电路结构 —— **只调它自己的参数**。这保证了合规性。

## 四、怎么证明结果可信

这是本项最要命的地方（**任一用例不等价就是 0 分**），所以我们用了**两套互相独立的方法**交叉验证，而且每套都自带"防自欺"机制。

### 4.1 方法一：形式化等价性证明（自研，4/4 通过）

把"优化前"和"优化后"两个电路并排接起来，构造一个"找不同"的电路，
然后让 SAT 求解器**穷举证明**：无论输入怎么变、时钟走多少拍，两者输出**永远相同**。

**防自欺机制**（很关键，否则检查器本身可能是坏的）：

* **自检**：拿同一个电路跟它自己比 —— **必须通过**。若不通过，说明检查器坏了。
* **负对照**：故意改坏一处电路 —— **必须报错**。若不报错，说明检查器检验不出问题、前面的"通过"不算数。

两个前置条件都满足后，正式结论才有效。

### 4.2 方法二：官方口径 EQY（2/4 通过）

按主办方答疑 C54-3 的原话（"abc 之后输出 ilang 交给 eqy 验证"）做的独立验证。
**test1、test2 通过**；test3、test4 未通过，原因是 EQY 工具本身的限制
（分区抽象、含存储器），**同样的失败也发生在官方原始流程上**，不是我们引入的问题；
答疑 C53-5 明确「切换设计模式验证是允许的，算作通过」，由方法一覆盖。

### 4.3 合规性自检

* 优化指令**全部**是 `abc9` 内部的命令，**没有**出现经典 `abc` 的命令（已用脚本扫描确认）
* 优化代码已**编进 `synth_intel`**（yosys 主程序），不是 `plugin` 加载
* 已实测确认：其他单元（触发器）**零增加**

```diff
+ run("pmux_opt -analyze-only");   // 早期阶段：在多路选择器被拆散前识别它们

+ run("pmux_opt" + ...);            // 映射阶段：改用我们选定的策略
```
